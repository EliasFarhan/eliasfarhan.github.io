On October 28th 2023, we ran the first edition of the **RGB Games Programming Conference**, the *Red for Indie Edition*, at the [Octagon](https://octagon.swiss/) in Geneva. RGB is a game tech conference for independent game developers, and our goal for this first edition was to gather game developers from Switzerland and the Auvergne-Rhône-Alpes region for a day of talks and networking.

## The facts

- **Event**: RGB 1st Games Programming Conference: Red for Indie Edition
- **Date**: October 28th 2023
- **Location**: [Octagon](https://octagon.swiss/)
- **Audience**: independent game developers from Switzerland and Auvergne-Rhône-Alpes
- **Site**: [rgbconf.ch/red](https://rgbconf.ch/red/)
